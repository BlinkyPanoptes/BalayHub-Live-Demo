# BalayHub

A dormitory and rental finder for Bacolod City. This is a front-end demo: static HTML, CSS and a little JavaScript, with no backend.

## Pages

- `index.html` — login (username `demo`, password `balayhub`)
- `listing.html` — searchable list of dormitories
- `amenities.html`, `areainfo.html`, `review.html` — detail pages for Antares Dormitory

## Run locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, pick `main` and `/ (root)`, then save.
4. After a minute the site is live at https://blinkypanoptes.github.io/BalayHub-Live-Demo/.
